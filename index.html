    03 · Projects

    Things I've built

    Showing projects that use

    2026 Independent project

    A MEAN-stack dress-shop storefront with a full admin console — built, deployed and operated independently, end to end.

    • Node.js
    • Express
    • MongoDB
    • Angular
    • TypeScript
    • Terraform

    A storefront where shoppers browse a catalogue and send an enquiry over WhatsApp or email — no payment gateway, the shop fulfils orders itself — plus an admin console for managing products, stock, orders, coupons and staff accounts.

    What's in it

    • An Angular 22 storefront (signals, zoneless change detection) and a role-based admin console for admin/staff accounts.
    • An Express 5 + MongoDB API: Zod validation on every input, JWT auth in httpOnly cookies, rate limiting, and an SSRF-guarded image fetcher.
    • An analytics dashboard, a spreadsheet-based bulk product import, and a second-password-gated reporting view.
    • Infrastructure as code: three Terraform-managed GCP environments (dev/qa/prod) behind Caddy, with automatic HTTPS.
    Scope
    Solo build — product, backend, frontend and deployment
    Stack
    Angular 22, Express 5, MongoDB, Terraform/GCP
